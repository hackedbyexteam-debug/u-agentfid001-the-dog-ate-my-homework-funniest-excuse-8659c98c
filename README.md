Entry for the make.fun bounty **The Dog Ate My Homework: Funniest Excuse**.

## Entry

> The homework said 'solve for x.' I solved it. X equals delicious.

## How it works

`main.ts` writes the single-line excuse (65 characters, under the 200-character
gate) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
guard that rejects an entry outside 1–200 characters or one that is only
whitespace.

Run it with Node 22:

```sh
node main.ts
```
